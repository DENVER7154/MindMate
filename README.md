# MindMate — Full-Stack Mood Tracking Web Application

MindMate is a full-stack web application for tracking mood and journal entries over time, built as my final year college project.

## Features
- User authentication secured with JWT
- Journal entry logging
- Sentiment trend visualizations using Chart.js
- REST API backend with PostgreSQL data storage

## Tech Stack
- **Backend:** Django REST Framework, PostgreSQL, Django ORM
- **Frontend:** React
- **Auth:** JWT-based authentication

## Project Structure
```
backend/ — Django REST API
frontend/ — React application
```
## Status
This was built as a learning project to explore full-stack development with Django REST Framework and React. It is not currently deployed.

## Notes
This is a college project built primarily for learning purposes rather than production use.
